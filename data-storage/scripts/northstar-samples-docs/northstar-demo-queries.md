# NorthStar Health Group: dynamic query showcase

NorthStar is a fictional, nationwide health company. This directory contains the
same 20 dynamic-query demonstrations written for each supported database type.
The data is synthetic and the reports are intended for provider comparison and
local demos.

## Provider query packs

| Database type | Query pack |
|---|---|
| SQLite | [northstar-demo-queries.sqlite.md](northstar-demo-queries.sqlite.md) |
| SQL Server | [northstar-demo-queries.sqlserver.md](northstar-demo-queries.sqlserver.md) |
| PostgreSQL | [northstar-demo-queries.postgresql.md](northstar-demo-queries.postgresql.md) |
| CockroachDB | [northstar-demo-queries.cockroach.md](northstar-demo-queries.cockroach.md) |
| MariaDB | [northstar-demo-queries.mariadb.md](northstar-demo-queries.mariadb.md) |
| SAP HANA | [northstar-demo-queries.saphana.md](northstar-demo-queries.saphana.md) |
| Firebird | [northstar-demo-queries.firebird.md](northstar-demo-queries.firebird.md) |
| Db2 | [northstar-demo-queries.db2.md](northstar-demo-queries.db2.md) |

Each provider file contains only that database type's SQL, while preserving the
shared Sales, Health care, Insurance, and Human resources report descriptions.
The seed data is synthetic and should not be treated as real patient, employee,
or customer data.
